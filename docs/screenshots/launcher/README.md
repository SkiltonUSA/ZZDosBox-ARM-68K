# Launcher 0.22.6-dev

Captured on the physical A4000TX / ZZ9000 on 19 October 2026.
Images are cropped to the launcher window from full Workbench captures;
no interface elements have been altered. Each main sidebar page is shown.
No guest workload ran during capture.

The CPU examples show 60,000 and 100,000 selected for illustration. Neither
high value was saved; the selected Duke profile remains at 10,000 cycles.
Other settings shown are illustrative, not a benchmark specification.
See the [Duke measurements](../../amiga-dosbox-duke-arm-optimisation.md)
for measured settings, game-clock progress and audio limitations.
