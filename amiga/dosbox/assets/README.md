# ZZDosBox artwork

`zzdosbox-logo.png` is the transparent master for the launcher splash screens
and 64px Workbench icons. The design preserves the DOSBox box silhouette and
DOS/BOX lettering, with two large Zs identifying the ZZ9000 version.

Created with the built-in image-generation tool from the supplied DOSBox ICO
reference. The original `dosbox.ico` is retained as the reference asset.
The generation brief is recorded in `zzdosbox-logo.prompt.txt`.

Run `scripts/prepare_dosbox_icon.py` to produce the native Amiga image data.
Generated headers remain in the local build directory.
