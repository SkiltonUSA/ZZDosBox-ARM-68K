# Launcher 0.19.10-dev

Incremental update for an existing 0.19.9 installation; replace only the
launcher executable with the application closed. MUI 3.8+ is required.

In Load program, click the program list or focus it with Tab. Up/Down selects
entries; a letter or number jumps to the first matching title. This applies
to All, Games, Applications and OS. No match leaves the selection unchanged.

About includes a scrollable changelog with the newest version first.

The 68k build passed with warnings treated as errors. The program-list
handler is built in; no external custom class is needed. Emulator binaries
and profile formats are unchanged.
