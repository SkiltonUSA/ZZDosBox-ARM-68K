# ZZDosBox 1.0 Beta launcher

[Executable](ZZDosBox-Launcher) · [Complete installers](https://github.com/SkiltonUSA/ZZDosBox-ARM-68K/releases/tag/v1.0.0-beta)

Adds shared USB/SD folders, a Workbench CD chooser for IDE/SCSI/USB drives,
and the disk helper standard-input fix. Existing emulator runtimes are unchanged.
For an existing installation, close ZZDosBox and replace the executable in PC.
Keep its support files and settings. Use the installer for a new installation.

[Shared drives and CDs](../../../docs/amiga-dosbox-shared-drives.md).
Build metadata records the source and executable hashes.
