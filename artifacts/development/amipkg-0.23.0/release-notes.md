Updated AmiPkg installers with the refreshed ZZDosBox launcher.

- Full-page settings forms, compact tabs and library categories.
- [i] About and scrolling status history.
- Layout checked on the Amiga at 640×480 and 1024×768 window budgets.
- Existing dependency checks and settings/save preservation behaviour retained.

**Standard:** empty library; add your own software. AHI is checked but sound-off use is allowed.

**With Demos:** same application plus Corridor 7, Doom 1.9 shareware and the non-interactive King's Quest VII Demo. AHI v4+, configured output modes and accessible unit 0 are required for the supplied profiles.

Extract either `.lha`, open its drawer and run **Install**. Choose the existing installation to upgrade. With Demos is complete; Standard is not needed first.

Emulator runtimes and demo payloads are unchanged from 0.22.7 Beta. The included launcher identifies itself as 0.23.0-dev. Both signed installers pass reproducibility, extracted-payload and checksum checks. A new hardware installer-upgrade test is pending; the launcher itself has been tested on the Amiga.
