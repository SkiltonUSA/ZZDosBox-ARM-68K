# Launcher 0.19.8-dev

Incremental update for an existing 0.19.7 installation. Copy
`ZZDosBox-Launcher` and `Network.guide` into the application drawer together.
Keep the existing runtime, disk helpers, compatibility data and configuration.

**Network guide** sits below the Network subtabs and opens the offline guide
in MultiView. Its linked contents cover TCP/IP, DHCP/manual IPv4, IPX, controls,
DOSBox-X differences and troubleshooting. MUI 3.8+ and MultiView are required.
The guide is generated from the same Markdown source as the GitHub documentation.

The 68K build passes with warnings treated as errors. Physical verification
is recorded in the accompanying validation note.
