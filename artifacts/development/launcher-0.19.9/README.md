# Launcher 0.19.9-dev

Incremental launcher update for an existing 0.19.8 installation. Replace
`ZZDosBox-Launcher` with the application closed; retain the existing support
files and settings. Requires MUI 3.8+.

The Display settings guide now always states: **Scanlines and Show FPS cannot
be used together.** Scanlines require fullscreen with the FPS counter off.
Rendering behaviour is unchanged. The 68k build passed with warnings treated
as errors.
