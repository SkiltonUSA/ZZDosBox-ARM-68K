# Scalable launcher — 0.22.7-dev

Launcher-only update for an existing ZZDosBox installation. Close the launcher,
retain a copy of its executable, then replace `ZZDosBox-Launcher` in the same
drawer. Keep existing configuration, support files and emulator runtimes.

- Compact typography, spacing and previews for smaller Workbench screens.
- Independent scrolling for every section; navigation and Save settings stay visible.
- Resizable viewport, with separate compact/regular remembered window geometry.
- Compact startup/loading panels; no global screen or font preference changes.

See [navigation](../../../docs/amiga-dosbox-launcher-navigation.md) and
[validation](validation.md). This launcher is included in both 0.22.7 Beta installer packages.
