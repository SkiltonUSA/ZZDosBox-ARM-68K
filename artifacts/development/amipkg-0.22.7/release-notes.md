ZZDosBox 0.22.7 Beta updates both offline AmiPkg installers with the scalable launcher.

- Compact layout for smaller Workbench screens, including 640×480 window budgets.
- Scrollable settings pages, smaller previews and loading cards; navigation remains visible.
- Standard: emulator with an empty library.
- With Demos: the same emulator plus Corridor 7, Doom 1.9 shareware and King’s Quest VII Demo.

Extract the chosen LHA and open Install. Choose the existing installation drawer to upgrade. Dependency checks and preservation of profiles, settings and saves are retained. Emulator runtimes and demo profiles/media are unchanged.

Both downloads include signed package catalogues. SHA-256 files are supplied alongside them. Small-screen testing used constrained windows on the physical Amiga’s existing desktop; no Workbench resolution or system preferences were changed.
