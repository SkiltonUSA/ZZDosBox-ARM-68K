# NEON / ARMv7 dynrec development build

Physically tested and installed DOS runtime, 13 October 2026. ARMv7 dynamic
recompiler, 4 MiB code cache, NEON pixels and bounded framebuffer overlap.
The executable is `pc/ZZDosBox-Dynrec`; installed under the name `ZZDosBox`.
Doom Demo3 measured 7.29 FPS; a later matched normal-output run measured 7.33.
This remains a development build. The separate Windows runtime is unchanged.
