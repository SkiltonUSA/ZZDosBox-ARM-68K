# ZZDosBox 1.0 Beta installers

[Download Standard or With Demos](https://github.com/SkiltonUSA/ZZDosBox-ARM-68K/releases/tag/v1.0.0-beta).

Both editions use the 1.0 Beta launcher, including shared folders and the
Workbench CD chooser. Existing runtime binaries, demo files and installer tools
are unchanged. See [installation and dependencies](../../../docs/amipkg-installers.md).

Verification records include signed catalogues, public keys, archive checksums,
reproducibility and extracted payload comparisons. No secret keys are included.

The Standard installer passed a fresh installation on the A4000TX. Dependency
checks and catalogue verification passed; AmiPkg doctor reported all 39 package
files healthy. The demo edition passed archive/payload verification; unchanged
demo media was not replayed for this packaging update.
