# Mouse development build

0.10.1-dev with DOS INT33 and BIOS PS/2 mouse input, including the Windows
A20/paging fixes. `pc/ZZDosBox` is the Amiga executable; the MUI launcher is
unchanged from [0.10.1](../../0.10.1-dev/launcher).

Requires [Amiga runtime dependencies](../../../docs/requirements.md).
[Tests and limitations](../../../amiga/records/2026-10-13/dosbox-mouse/findings.md).
No games, Microsoft mouse driver or guest disk images are bundled.
