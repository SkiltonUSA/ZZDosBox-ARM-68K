# Launcher 0.19.7-dev

Incremental launcher update for an existing ZZDosBox installation. Copy the
included files beside your existing runtimes. MUI 3.8+ is required.

Adds sidebar navigation, ZZDosBox branding and loading screens, raw-image
browsing, contextual display help and 32/64/128/256 MiB FAT16 image creation.
Workbench image access needs diskimage.device, DiskImageCtrl and fat95.
Images are raw `.IMG`, not Microsoft VHD containers. Embedded DOSBox DOS 5
needs no installation media; optional MS-DOS 6.22 requires your installed files.
Microsoft software and personal settings are not included.

See [requirements](../../../docs/requirements.md) and `launcher-build.json`.
